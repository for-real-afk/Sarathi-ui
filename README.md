# Saarthi Reach Foundation — Welfare Discovery & Eligibility Portal

This is the React frontend application for the **Saarthi Welfare Intelligence Platform**. The platform is designed to help citizens and social workers in Andhra Pradesh and Telangana discover government welfare schemes, evaluate eligibility deterministically, and resolve documentation gaps using a RAG-powered AI Assistant.

---

## 🚀 Key Features

1. **Household Welfare Survey (Wizard)**:
   - A multi-stage survey (Sections A to K) covering Identity, Household structure, Income, Assets, Health, existing Welfare status, and Consent.
   - Strict client-side validation ensuring clean profiles are captured.

2. **Welfare Eligibility Dashboard (Dual-Layout)**:
   - Activates automatically upon survey submission.
   - **Left Panel (Eligibility Matcher & Document Gaps)**:
     - Real-time display of matched welfare schemes parsed from the backend rule engine.
     - Colorful eligibility badges: `ELIGIBLE` (green), `PARTIALLY_ELIGIBLE` (amber), and `NOT_ELIGIBLE` (red).
     - Individual Match Scores indicating compliance depth.
     - Deep explanation reasons detailing *why* the citizen matches or fails rules.
     - **Document Gap Analysis**: A comparative checklist showing required versus missing documents (e.g. Income Certificate, Ration Card) with dynamic advice on resolving gaps.
     - **Traceable Citations**: References to specific document source pages and database verification statuses.
   - **Right Panel (Welfare Agent Interactive Chat)**:
     - Direct conversational bridge with the FastAPI RAG assistant.
     - Formatted text rendering on-the-fly for clean bullet lists, bold text, and headers.
     - **Quick Query Chips**: Hotkeys to instantly trigger frequent queries (e.g., "What are the rules for Aasara Pension?", "What documents are missing for me?").
     - Live typing loading indicators.

## 🔌 Backend Connection & Data Flow

The frontend connects directly to the **Saarthi Welfare Backend** (running on port `4000` by default):

1. **Survey Submission**:
   - `POST http://localhost:4000/api/surveys`
   - Submits the flattened survey answers as JSON for historical record storage and auditing.
2. **Initial Eligibility & Chat Initialization**:
   - `POST http://localhost:4000/chat/completions`
   - Sends the current profile with the query: *"Show my eligible welfare schemes and document recommendations based on my profile."*
   - Receives:
     - `response`: Conversational overview generated by the LLM.
     - `recommendations`: Structured eligibility analysis mapping out state regulations, missing documents, and action steps.
     - `retrieved_sources`: Citable database segments used for RAG grounding.
3. **Conversational RAG Chat Loop**:
   - `POST http://localhost:4000/chat/completions`
   - Transmits user questions along with the last 5 conversation history logs to preserve context.

## 🛠️ Local Development & Running

### Prerequisites
- Node.js (v16+) installed.
- **Saarthi Backend** running on port `4000` (refer to the backend repository instructions).

### Setup Instructions

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run the React Development Server**:
   ```bash
   npm start# it took this command to start in my local npx react-scripts start
   ```
   The browser will automatically open to `http://localhost:3000`.

3. **Production Build**:
   ```bash
   npm run build
   ```

## 📂 Codebase Layout

- `src/App.jsx`: Main React router, orchestrates wizard sections, manages state for chat history (`chatMessages`), active recommendations (`chatRecommendations`), and triggers HTTP integrations with the FastAPI server.
- `src/theme.js`: Central styling token palette (Warm Amber × Deep Slate) using customized visual guidelines.
- `src/sections/`: Individual survey form components for sections A through K.
